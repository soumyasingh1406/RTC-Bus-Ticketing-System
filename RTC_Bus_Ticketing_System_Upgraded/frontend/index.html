ABOUT THE PROJECT

RTC Bus Ticketing System

A C++ object-oriented bus reservation prototype with a browser-based interface.

01

Search and selection

Search sample routes, compare four bus categories and view seat availability.

02

Object-oriented design

Uses an abstract Bus class, derived bus categories, Passenger, Ticket and BookingSystem classes.

03

Booking management

Creates a booking ID, stores booking records, supports ticket lookup and cancellation.

Academic prototype notice

Route and fare information is sample data for demonstration. This project is not connected to live RTC schedules, real-time inventory or online payments.
